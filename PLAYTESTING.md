# Playtesting the hardened candidate

The 8.2C baseline is human verified. This rebuilt candidate needs a short equivalence/font check before publication review: launch manually; F8; ordinary riding/tricks; several mini-ramp wall-to-wall cycles and handplant; F8 current-position exit; empty/carry jumps and one voice; all four board selectors; Object Dropper place/rotate/grind/delete; prop carry/release; marker/camera; water return; grotto camera; long LINE; F9; Child/Adult Link; quit/relaunch.

Compare movement/input timing to the golden baseline. At 1080p, 1440p and 4K inspect the OFL font for compact score, stable right-aligned digits, readable prompts/options and long object names. Check the resource-missing fallback in an isolated copied package, then restore it.

Report build ID, resolution/FPS, scene/room, Adult/Child, input bindings, active cheats/mods, selected prop/board and exact steps. Attach a short clip and trimmed log when helpful. Automated fixtures do not prove human-visible animation or gameplay feel.
